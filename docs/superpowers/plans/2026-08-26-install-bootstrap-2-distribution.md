# Install Bootstrap — Plan 2: Distribution, Release Assets and Docs

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `mymcp init` (delivered by Plan 1) into a genuine one-liner — `curl … | sudo bash` — by shipping raw binaries in each GitHub Release, a thin `install.sh` that only fetches and verifies them, and documentation that stops telling operators to hand-write systemd units.

**Architecture:** `scripts/install.sh` contains zero configuration logic. It detects the architecture, obtains the binary (pipx when present, else a checksum-verified raw binary from the release), and `exec`s `mymcp init "$@"`. Release assets are published from binaries CI already builds but has never uploaded. The repo's `.env.example` becomes generated output of the Go embedded template, with a CI drift gate.

**Tech Stack:** POSIX-ish bash (`set -euo pipefail`), shellcheck, GitHub Actions (`softprops/action-gh-release@v3`), Python's `http.server` as the test fixture.

**Spec:** `docs/superpowers/specs/2026-08-26-install-bootstrap-design.md`

**Depends on:** Plan 1 (`docs/superpowers/plans/2026-08-26-install-bootstrap-1-go-core.md`) must be complete — `install.sh` ends by exec'ing `mymcp init`, and Task 4 here calls `mymcp config example`.

## Global Constraints

- **`install.sh` contains no configuration logic.** Its entire failure surface is: detect arch, download, verify checksum, place the file, `exec`. Anything about ports, tokens, units or `.env` belongs in `mymcp init`.
- **Asset URLs use `https://github.com/algony-tony/mymcp/releases/latest/download/<asset>`** — never the GitHub API. Unauthenticated API rate limits behind NAT are the classic `curl | bash` failure, and the `latest/download` form guarantees the script and the binary it fetches come from the same release.
- **Supported platforms:** Linux `x86_64`→`amd64` and `aarch64`→`arm64`. Anything else exits with a clear message, never a partial install.
- **Checksum verification is mandatory** on the raw-binary path. A missing or mismatched `SHA256SUMS` entry aborts the install.
- **`install.sh` must pass `shellcheck` with no warnings** and be exercised by tests before release.
- **Never hardcode a version** in the script's default path; `--version X.Y.Z` pins explicitly.

"""Drive scripts/install.sh against a local release mirror.

The script's whole job is fetch-verify-place, so these tests cover exactly
that: the happy path, a tampered binary, and an unsupported architecture.
`mymcp init` is stubbed by putting a fake `mymcp` earlier on PATH, because
install.sh must not care what init does.
"""

import hashlib
import http.server
import os
import subprocess
import threading
from pathlib import Path

import pytest

REPO = Path(__file__).resolve().parents[2]
SCRIPT = REPO / "scripts" / "install.sh"


@pytest.fixture
def release_mirror(tmp_path):
    """Serve a fake 'releases/latest/download/' tree over HTTP."""
    root = tmp_path / "mirror"
    root.mkdir()
    payload = b"#!/bin/sh\necho fake-mymcp\n"
    (root / "mymcp-linux-amd64").write_bytes(payload)
    digest = hashlib.sha256(payload).hexdigest()
    (root / "SHA256SUMS").write_text(f"{digest}  mymcp-linux-amd64\n")

    # SimpleHTTPRequestHandler resolves against cwd, so pin the directory.
    class Handler(http.server.SimpleHTTPRequestHandler):
        def __init__(self, *a, **kw):
            super().__init__(*a, directory=str(root), **kw)

    server = http.server.ThreadingHTTPServer(("127.0.0.1", 0), Handler)
    thread = threading.Thread(target=server.serve_forever, daemon=True)
    thread.start()
    yield f"http://127.0.0.1:{server.server_address[1]}", root
    server.shutdown()


def run_install(base_url, tmp_path, *args, arch="x86_64"):
    """Run install.sh with a stub `uname` and a stub `mymcp` on PATH."""
    stub = tmp_path / "stub"
    stub.mkdir(exist_ok=True)
    (stub / "uname").write_text(
        f'#!/bin/sh\ncase "$1" in -m) echo {arch};; -s) echo Linux;; *) echo Linux;; esac\n'
    )
    (stub / "uname").chmod(0o755)
    env = dict(os.environ)
    env["MYMCP_INSTALL_BASE_URL"] = base_url
    env["PATH"] = f"{stub}:{env['PATH']}"
    return subprocess.run(
        ["bash", str(SCRIPT), "--bin-dir", str(tmp_path / "bin"), *args],
        capture_output=True,
        text=True,
        env=env,
    )


def test_installs_verified_binary_and_execs_init(release_mirror, tmp_path):
    base_url, _ = release_mirror
    r = run_install(base_url, tmp_path, "--method", "binary", "--yes")
    assert r.returncode == 0, r.stderr
    installed = tmp_path / "bin" / "mymcp"
    assert installed.exists(), r.stderr
    assert os.access(installed, os.X_OK)
    # install.sh exec's `mymcp init`; the fake binary echoes, proving handoff.
    assert "fake-mymcp" in r.stdout


def test_aborts_on_checksum_mismatch(release_mirror, tmp_path):

    assert r.returncode != 0
    assert "checksum" in (r.stderr + r.stdout).lower()
    assert not (tmp_path / "bin" / "mymcp").exists(), "a failed verify must leave nothing behind"


def test_rejects_unsupported_architecture(release_mirror, tmp_path):

    r = run_install(base_url, tmp_path, "--method", "binary", arch="riscv64")
    assert r.returncode != 0
    assert "riscv64" in (r.stderr + r.stdout)

```bash
#!/usr/bin/env bash
# mymcp installer. This script ONLY gets the binary onto the machine; every
# configuration decision belongs to `mymcp init`, which it exec's at the end.
#
#   curl -fsSL https://github.com/algony-tony/mymcp/releases/latest/download/install.sh | sudo bash
#   curl -fsSL … | sudo bash -s -- --yes --port 9000
set -euo pipefail

REPO_URL="https://github.com/algony-tony/mymcp/releases"
BASE_URL="${MYMCP_INSTALL_BASE_URL:-$REPO_URL/latest/download}"
METHOD="auto"
VERSION=""
BIN_DIR="/usr/local/bin"
INIT_ARGS=()

die() { echo "install.sh: $*" >&2; exit 1; }
have() { command -v "$1" >/dev/null 2>&1; }

while [ $# -gt 0 ]; do
    case "$1" in
        --method)  METHOD="$2"; shift 2 ;;
        --version) VERSION="$2"; shift 2 ;;
        --bin-dir) BIN_DIR="$2"; shift 2 ;;
        --help)
            echo "usage: install.sh [--method auto|pipx|binary] [--version X.Y.Z] [--bin-dir DIR] [mymcp init flags…]"
            exit 0 ;;
        *) INIT_ARGS+=("$1"); shift ;;   # everything else is for `mymcp init`
    esac
done

[ "$(uname -s)" = "Linux" ] || die "mymcp only runs on Linux (found $(uname -s))"
MACHINE="$(uname -m)"
case "$MACHINE" in
    x86_64)  ARCH="amd64" ;;
    aarch64) ARCH="arm64" ;;
    *) die "unsupported architecture: $MACHINE (mymcp ships amd64 and arm64)" ;;
esac

if [ -n "$VERSION" ] && [ -z "${MYMCP_INSTALL_BASE_URL:-}" ]; then
    BASE_URL="$REPO_URL/download/v$VERSION"
fi

fetch() {  # fetch <url> <dest>
    if have curl; then
        curl -fsSL "$1" -o "$2"
    elif have wget; then
        wget -qO "$2" "$1"
    else
        die "neither curl nor wget is available"
    fi
}

install_binary() {
    local tmp asset sums want got
    tmp="$(mktemp -d)"
    # shellcheck disable=SC2064  # expand tmp now, not at trap time
    trap "rm -rf '$tmp'" EXIT
    asset="mymcp-linux-$ARCH"

    echo "==> downloading $asset"
    fetch "$BASE_URL/$asset" "$tmp/$asset" || die "download failed: $BASE_URL/$asset"
    fetch "$BASE_URL/SHA256SUMS" "$tmp/SHA256SUMS" || die "could not fetch SHA256SUMS"

    sums="$(grep " $asset\$" "$tmp/SHA256SUMS" || true)"
    [ -n "$sums" ] || die "no checksum entry for $asset in SHA256SUMS"
    want="${sums%% *}"
    got="$(sha256sum "$tmp/$asset" | cut -d' ' -f1)"
    [ "$want" = "$got" ] || die "checksum mismatch for $asset (want $want, got $got)"
    echo "==> checksum verified"

    mkdir -p "$BIN_DIR"
    install -m 0755 "$tmp/$asset" "$BIN_DIR/mymcp"
    echo "==> installed $BIN_DIR/mymcp"
    export PATH="$BIN_DIR:$PATH"
}

install_pipx() {
    echo "==> installing via pipx"
    if pipx list 2>/dev/null | grep -q algony-mymcp; then
        pipx upgrade algony-mymcp
    elif [ -n "$VERSION" ]; then
        pipx install "algony-mymcp==$VERSION"
    else
        pipx install algony-mymcp
    fi
}

case "$METHOD" in
    pipx)   have pipx || die "--method pipx but pipx is not installed"; install_pipx ;;
    binary) install_binary ;;
    auto)   if have pipx; then install_pipx; else install_binary; fi ;;
    *) die "unknown --method: $METHOD" ;;
esac

have mymcp || die "mymcp is not on PATH after install; check $BIN_DIR"

echo "==> handing off to mymcp init"
exec mymcp init "${INIT_ARGS[@]}"
```

import re
from pathlib import Path

import yaml

SCRIPT = REPO / "scripts" / "install.sh"


def _release_files() -> str:
    data = yaml.safe_load(WORKFLOW.read_text())
    blobs = []
    for job in data["jobs"].values():
        for step in job.get("steps", []):
            if "action-gh-release" in str(step.get("uses", "")):
                blobs.append(str(step.get("with", {}).get("files", "")))
    assert blobs, "no action-gh-release step found"

### Already have pipx?

`pipx install` on its own only places the binary — it cannot write
